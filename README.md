# Dostaffkin

**Dostaffkin** — это современное клиентское веб-приложение на Angular 21, разработанное для логистических платформ и сервисов доставки. Интерфейс приложения оптимизирован для работы как на десктопных, так и на мобильных устройствах, обеспечивая удобное отслеживание отправлений и оформление заказов.

---

### 🛠 Технологический стек

*   **Фреймворк:** Angular 21 (компоненты, реактивные формы, маршрутизация)
*   **Язык программирования:** TypeScript 5.9
*   **Архитектура стилей:** Нативный CSS3 (с использованием CSS-переменных для темизации)
*   **Управление потоками данных:** RxJS 7.8
*   **Тестирование и окружение:** Vitest 4.0 + JSDom 27
*   **Пакетный менеджер:** NPM 10.9.2

---

### 📂 Структура проекта (Архитектура `src`)

Проект организован по модульному принципу Angular (компоненты разделены на страницы и глобальные элементы):

```text
src/
├── app/
│   ├── header/                        # Глобальная шапка сайта (навигация)
│   │   ├── header.ts                  # Класс компонента HeaderComponent
│   │   ├── header.html                # Шаблон со ссылками на страницы
│   │   └── header.css                 # Стили шапки и адаптивного меню
│   ├── pages/                         # Основные экраны (страницы) приложения
│   │   ├── home/                      # Главная страница (Промо / Интро)
│   │   ├── order/                     # Страница создания и расчета заказа
│   │   │   ├── order.config.ts        # Конфигурация / константы формы заказа
│   │   │   └── ...
│   │   └── track/                     # Страница интерактивного трекинга
│   ├── services/                      # Сервисный слой для работы с API
│   │   └── delivery-api.ts            # DeliveryApiService (запросы к бэкенду)
│   ├── app.config.ts                  # Глобальная конфигурация приложения (ApplicationConfig)
│   ├── app.routes.ts                  # Конфигурация маршрутизации (Routes)
│   └── app.ts                         # Корневой компонент (AppComponent)
├── index.html                         # Главная HTML-страница приложения
├── main.ts                            # Точка входа для запуска Angular
└── styles.css                         # Глобальные стили и переменные темы
```

### ✨ Ключевой функционал и Эндпоинты

#### 1. Модуль отслеживания (Track)
*   Интерактивная страница `TrackComponent` для проверки статуса посылки по трек-номеру.
*   Интеграция с бэкендом для динамического обновления этапов доставки.

#### 2. Модуль оформления заказов (Order)
*   Многошаговая или комплексная форма `OrderComponent` на базе `@angular/forms`.
*   Валидация адресов отправления/получения, габаритов груза и расчет стоимости.

#### 3. Сервис интеграции (DeliveryApiService)
Централизованный сервис `DeliveryApiService` инкапсулирует в себе HTTP-запросы к API для:
*   Создания новых отправлений.
*   Получения истории и статусов доставки в реальном времени через RxJS-потоки.

#### 4. Навигационный хаб
*   Глобальный `HeaderComponent` предоставляет бесшовную SPA-навигацию без перезагрузки страниц между разделами Главная, Заказ и Трекинг.

### 🚀 Инструкция по установке и запуску

#### 1. Подготовка окружения
Убедитесь, что на вашем компьютере установлена актуальная версия Node.js и пакетный менеджер **NPM 10.9.2**.

#### 2. Установка зависимостей
Разверните локальные пакеты проекта, выполнив команду в терминале:
```bash
npm install
```

#### 3. Команды автоматизации (Скрипты)
Запуск команд производится через `npm run <команда>`:

*   `npm run start` — запускает локальный сервер для разработки (`http://localhost:4200`) с поддержкой Hot Module Replacement (HMR).
*   `npm run build` — компилирует приложение и собирает оптимизированные Production-файлы в директорию `dist/`.
*   `npm run watch` — запускает компиляцию в режиме разработки, автоматически пересобирая проект при изменении файлов.
*   `npm run test` — запускает модульные тесты в сверхбыстрой среде Vitest с эмуляцией JSDom.
